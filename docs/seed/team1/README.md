## 넣지 않는 것

- BP 관리자·가맹 관리자 권한 그룹 — 각 BP가 화면에서 만든다
- 직원 계정 · 알림 · 메일 양식 — 3팀 소유
- 임시공휴일·선거일 — 공공 API 동기화로만 받는다

## 확인할 것

- **약관 유형(`TERMS_TYPE`) 코드값:** ERD(`c1a05da`, 2026-10-02)는 6종(`TERMS_SERVICE` · `PRIVACY_COLLECT` · `STAFF_TERMS_SERVICE` · `STAFF_PRIVACY_COLLECT` · `MARKETING` · `LOCATION`)인데, 요청서는 4종(`TERMS_OF_USE` 등)이다. 요청서의 공통코드 ⑫와 약관 버전(Ⅱ-5)을 ERD에 맞춘다.
- **기본키 이름:** 네이밍 규칙이 2026-10-02 에 `{참조 단수}_id` 로 바뀌었다. 요청서는 ERD를 따르라고만 적어 두어 영향은 없지만, ERD 물리 모델(`schema.sql`)과 한 번 맞춰 본다.
- **AUTH_TYPE 코드값:** 권한 코드 규칙 때문에 `PM` 형식을 쓴다. 3팀 용어집은 `PLATFORM_MASTER` 형식이라 두 팀이 합의해야 한다.
- **Whale ERP 추가 메뉴:** 메뉴구조도에서 찾은 27건이다. URL 은 3팀 화면 경로와 맞춘다.
- **공휴일 규칙:** 실제 법령으로 한 번 확인한다.
