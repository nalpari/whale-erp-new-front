아무것도 고르지 않고 신규 메뉴를 누르면 최상위(1단계) 메뉴로 등록합니다.

신규 메뉴 등록 1단계 · 저장 전

코드는 저장할 때 확정됩니다. 순서는 상위 메뉴의 맨 끝이고, 저장 뒤 트리에서 옮깁니다.
메뉴 사용 상태
사용중지하면 사용자 화면에서 빠지고 새로 권한을 줄 수 없습니다. 이미 준 권한은 남습니다.
저장한 메뉴는 권한 관리의 메뉴 등록 팝업에 바로 나타납니다. 권한은 거기서 따로 줍니다.
