답변

답변을 저장하면 상담이 완료되고, 문의자에게 답변 메일이 자동 발송됩니다.

도입문의 답변은 이력 없이 하나다. 답변 완료 뒤 「답변 수정」으로 고치면 지금 답변을 덮어쓰고 이전 답변은 남지 않는다(문의사항과 다르다, 2026-10-19 재영). 고쳐도 상태는 답변 완료 그대로이고 운영 알림 · 메일은 다시 가지 않는다. 문의자 답변 메일은 처음 저장할 때 한 번 간다(WHALEERP-588). 답변자 · 답변 시각이 남는다. 답변 완료 건에는 답변 메일 줄이 선다 — 마지막 발송 결과(성공 · 실패)와 시각, 그리고 [답변 메일 재발송](2026-11-06 사용자 지정 — 전엔 「답변 메일 다시 보내기」). 재발송은 답변 완료 건에만 있고 저장된 지금 답변을 보낸다. 같은 도입문의는 1분 간격으로만 되고 플랫폼 운영자만 쓴다(WHALEERP-597). 누르면 재발송 확인창(아래 pop-resend), 보내면 토스트 「답변 메일을 재발송했습니다.」, 실패하면 띠 「답변 메일을 재발송하지 못했습니다. 잠시 후 다시 시도해 주세요.」. 「답변 수정」 저장 옆 안내는 「수정한 답변은 문의자에게 자동으로 발송되지 않습니다. 수정 내용을 전달하려면 저장 후 [답변 메일 재발송]을 눌러 주세요.」이고, 저장하면 토스트 「답변을 수정했습니다.」 뒤 수정 재발송 확인창(pop-resend-edit)을 띄운다. 마지막 메일이 1분 안이면 대신 안내창(pop-resend-wait)이다. 다른 운영자가 먼저 저장했으면 덮어쓰지 않고 최신 내용을 다시 확인하게 한다.
