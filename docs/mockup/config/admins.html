매핑 점포 범위 안에 미사용 가맹 관리자 계정이 없습니다.

흐린 줄이 미사용 계정이다 — 로그인과 ERP 이용이 막혔지만 상세와 변경 이력은 그대로 남는다. BP 마스터 계정은 플랫폼 BP 관리에서 다루므로 이 목록에 없다. 가맹 관리자 줄은 여기서 조회만 하고, 수정·비밀번호 초기화는 연결된 가맹 마스터만 한다. 권한 그룹은 BP 권한 그룹 관리의 값과 같다.

가맹 쪽 사용자에게는 본인 매핑 점포 범위의 가맹 관리자 계정만 보인다. BP 관리자와 가맹 마스터 계정은 조회 대상이 아니다. 가맹 관리자는 계정을 조회만 하고 등록·수정하지 않는다.
