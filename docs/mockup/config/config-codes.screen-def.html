"목업 권한"·"목업 상태" 토글은 실제 화면 요소가 아니라 목업 자체의 전환 컨트롤이라 번호에서 제외했다. 상단 GNB와 좌측 LNB는 이 화면정의서 스크린샷 자체에서 제외했다(embed 모드). 플랫폼고정 그룹(예: ROLE_TYPE)을 고르면 오른쪽 상세 코드 표의 모든 칸이 읽기 전용으로 바뀌고 추가·저장 버튼이 비활성화된다 — 레이아웃은 같아 별도로 캡처하지 않고 상세 코드 추가·저장 버튼 설명에 규칙을 정리했다. BP 관리자(조회만) 역할과 플랫폼 사용자 역할로 보면 코드명·표시순서·사용상태가 입력란 대신 읽기 전용 텍스트/배지로 보이고 추가·저장 버튼 자체가 없다.
