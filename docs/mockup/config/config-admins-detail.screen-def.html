"목업 권한"·"목업 계정" 토글은 실제 화면 요소가 아니라 목업 자체의 전환 컨트롤이라 번호에서 제외했다. 상단 GNB와 좌측 LNB는 이 화면정의서 스크린샷 자체에서 제외했다(embed 모드). 이 화면의 모든 값은 읽기 전용이고, 고치는 일은 수정 화면이 맡는다. 가맹 관리자 계정(moriyn)을 열면 레이아웃은 같고 기본정보 표 맨 끝에 「연결 가맹마스터」 줄이 하나 붙는 정도라 별도로 찍지 않았다(번호는 연결 가맹마스터 항목으로 둔다). 본인 계정의 「내 계정입니다.」 띠 · 가맹 관리자 계정을 다른 역할이 볼 때의 「이 계정은 연결된 가맹마스터만 수정할 수 있습니다.」 띠 · 등록 직후의 「초기화 비밀번호를 발송했습니다.」 띠는 이 스크린샷(BP 마스터 · hghr)에 없어 번호를 붙이지 않았다. 미사용 계정은 안내 띠 없이 미사용 배지만 보인다. 볼 수 없는 계정을 주소로 열면(없는 계정 · 다른 BP · 범위 밖 · BP 마스터 계정 · 가맹 쪽이 BP 쪽 계정을 연 경우) 경우와 관계없이 「볼 수 없거나 없는 계정입니다.」 한 문구와 [닫기]만 보인다. 소속 BP(BP코드 · 상호명)는 헤더의 BP 선택이 정하므로 이 화면에 두지 않는다(2026-10-29 사용자 결정, 코드대로).
