가맹 관리자는 이 화면에서 어느 역할의 계정도 등록하지 않습니다. 가맹 관리자 계정이 더 필요하면 연결된 가맹 마스터에게 요청해 주세요.

관리자 목록으로

이 상태는 가맹 마스터가 가맹 관리자를 등록할 때 생긴다. 목업 권한을 ‘가맹 마스터’로 두고 본다.

이 상태는 BP 쪽 사용자나 플랫폼 사용자가 등록할 때 생긴다. 가맹 마스터의 역할 선택지는 가맹 관리자 하나뿐이다.

온기 점장(FA000004)은 다른 가맹 마스터(ongi_fm)가 만든 권한 그룹입니다. 관리계정ID 가 본인(morinam01)인 그룹에서 골라 주세요.

가맹 관리자 계정은 가맹 마스터만 등록할 수 있습니다

메뉴 등록 권한이 있어도 BP 마스터 · BP 관리자 · 플랫폼 사용자는 가맹 관리자를 만들 수 없어 요청을 처리하지 않았습니다.

계정 역할

권한 그룹 구성은 BP 권한 그룹 관리에서
가맹 관리자는 가맹 마스터만 등록해 여기 없습니다. 가맹 관리자 계정은 가맹 마스터만 등록할 수 있습니다.
사용 중인 BP 관리자 그룹만 나옵니다. 사용 중지된 점포 조회 전용(BA000007)은 고를 수 없습니다. 가맹 마스터는 플랫폼이 정한 고정 권한 하나만 씁니다.
가맹 마스터가 등록할 수 있는 역할은 이것 하나입니다.
본인이 관리계정ID 인 사용 중 그룹만 나옵니다. 다른 가맹 마스터의 그룹은 보이지 않습니다. 가맹 관리자 권한 그룹을 먼저 만들어야 합니다. 선택할 수 없는 권한입니다.
등록하는 본인으로 고정되고 등록 뒤에도 다른 가맹 마스터로 바꾸지 못합니다.
