점포는 로그인 계정이 아니라 BP 의 운영 단위다

직영(일반점포)과 가맹(가맹점포)을 같은 구조로 다룬다. 상태는 미운영 → 운영 → 폐점 한 방향으로만 가고, 운영 전환은 사업자정보 인증이 끝나야 된다. 폐점은 조건(근로계약·구독·정산)을 채워야 하고 한 번 폐점하면 되돌릴 수 없다. 각 화면 위의 점선 줄로 역할과 상태를 바꿔 가며 무엇이 보이고 막히는지 볼 수 있다.

상태 · 권한

7
  • 전환은 미운영→운영, 미운영·운영→폐점뿐이다. 운영을 미운영으로 되돌리지 않고, 폐점을 다시 열려면 새 점포로 등록한다.S-MNRZOM
  • 운영 전환 조건은 사업자정보 인증 완료와 소속 BP 사용 상태 둘이다. 휴업·폐업 사업자인지는 보지 않는다.S-MNRZOM
  • 폐점 조건은 유효한 근로계약 0건 · 이용 중인 구독 0건 · 정산 대기 0원. 폐점일은 바꾼 날로 자동이고 사유는 받지 않는다.S-MNRZOM
  • 소속 BP 가 미사용이면 목록·상세 조회만 되고 등록·수정·상태 변경·삭제는 막는다. 점포 상태는 그대로 둔다.F-MOQKGY
  • BP 가 탈퇴하면 그 BP 의 미운영·운영 점포를 조건 검사 없이 모두 폐점한다.F-MOQKGY · S-JHQQNR
  • 가맹 마스터·가맹 관리자는 등록 권한이 켜져 있어도 점포를 등록할 수 없고, 매핑된 점포만 보고 고친다.S-ALHLHW
  • 쟁점 확정 점포 상태 변경은 점포 수정 권한이 있으면 역할을 가리지 않는다. 가맹 마스터·가맹 관리자도 매핑된 점포의 상태를 바꾼다.S-MNRZOM · STORE-1
  • 쟁점 확정 운영으로 바꾸거나 이미 운영인 점포는 점포 기본정보와 점포 사업자정보가 모두 필수다. 빈 곳이 있으면 운영으로 바꾸지 않는다.S-MNRZOM · STORE-2
  • 새 점포는 등록한 사람과 같은 BP 의 전체 점포 범위 사용자에게 자동으로 매핑된다. 플랫폼 사용자는 매핑 없이 전체를 본다.F-MOQKGY
