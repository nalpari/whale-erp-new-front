1팀 작업 영역 개요
R-KJGJXP · system/
플랫폼 운영 인력의 계정·권한과, 모든 BP 가 함께 쓰는 기준정보를 다룬다

플랫폼 사용자는 점포 매핑 없이 전체 BP 를 대상으로 일하고, 무엇을 할 수 있는지는 역할과 메뉴별 CRUD 권한으로만 판정한다. BP 측 관리자 계정·BP 권한 그룹·BP 공통코드·BP 휴일은 BP 환경 설정의 몫이라 여기 없다. 각 화면 위의 점선 줄로 보는 사람의 권한과 화면 상태를 바꿔 가며 무엇이 보이고 막히는지 볼 수 있다.

계정 · 권한

7
  • 플랫폼 계정 상태는 사용·미사용 둘뿐이다. 탈퇴가 없고, 미사용은 즉시 세션을 끊지만 데이터와 이력은 남긴다.PL-CUECAY
  • 플랫폼 마스터는 여럿 둘 수 있고, 사용 상태 플랫폼 마스터가 늘 한 명 이상이어야 한다. 마지막 한 명은 미사용·강등·삭제가 안 된다.F-RVDLOW
  • 플랫폼 마스터 계정은 플랫폼 마스터만 등록·수정·삭제·초기화한다. 누가 누구를 바꾸는지는 메뉴 권한 · 마스터 보호 · 본인 보호 셋으로만 가린다.F-RVDLOW
  • 본인의 권한과 상태는 스스로 못 바꾸고, 본인 계정은 삭제·초기화도 여기서 안 한다. 기본정보는 고칠 수 있다.S-CZGHBS
  • 권한 변경은 재로그인 없이 다음 요청부터 적용하고, 메뉴 모양은 다음 화면 이동이나 새로고침 때 바뀐다.PL-AMTMVC
  • 고정 권한은 플랫폼 마스터·플랫폼 관리자·BP 마스터·가맹 마스터 넷, 각 한 건이다. 플랫폼 마스터는 전체 허용 고정이라 조회만 된다. 삭제는 플랫폼 관리자 유형만.S-JDCOAG
  • 추가 권한의 CRUD 는 기준 고정 권한을, 설정자 본인의 권한 범위를 넘지 못한다. 등록·수정·삭제를 켜면 조회가 같이 켜지고 조회를 끄면 셋이 같이 꺼진다.S-EFQREM

기준정보 · 이력

7
  • 권한 코드는 권한 유형 + 6자리 순번(PM000001), 메뉴 코드는 MN + 6자리. 자동 채번이고 바꿀 수 없으며 삭제한 순번은 다시 쓰지 않는다.PL-EIMSQF
  • 아이디는 삭제·탈퇴 계정까지 포함해 다시 쓸 수 없고, 이메일은 사용·미사용 계정 사이에서만 겹치면 안 된다.PL-OCJOFP
  • 메뉴는 서비스 단위로 최대 3단계. 같은 서비스 안에서만 옮기고 하위가 함께 간다. 메뉴 삭제와 메뉴 변경 이력은 두지 않는다.F-CWWQUR
  • 서비스 목록은 플랫폼고정 공통코드 그룹 ‘서비스’다. 코드는 직접 입력하고 바꾸지 않으며, 사용 중지하면 새 메뉴·새 권한에서만 빠진다.F-LOUVWE
  • 관리 주체는 그룹에만 둔다(플랫폼고정·플랫폼제공). 상세 코드는 그룹을 따르고, BP 가 추가한 BP전용 코드는 이 화면에 없다.PL-VOCZCE
  • 플랫폼 휴일은 대한민국 공식 휴일만, 동기화 배치만 채운다. 토·일은 휴일 데이터가 아니고 한 날짜에 한 건이다.F-CNPWOQ
  • 휴일 변경 이력과 동기화 이력은 데이터로만 남기고 화면이 없다. 계정 변경 이력은 상세에서 보이고, 삭제한 계정은 데이터로만 남는다.PL-HKZBNU · S-BRSPGB

마스터 계정은 마스터만 바꾸고, 로그인한 마스터는 늘 사용 상태다. 그래서 남은 한 명이 다른 사람일 수는 없고, 본인 보호와 겹친다. 둘이 서로를 동시에 강등하는 경우만 남으니 화면 안내보다 서버의 동시 검사를 명세에 적을지 정해야 한다. 목업의 이 상태는 plat_jung 을 열고 plat_kim 이 미사용이라고 가정했다.

SYSTEM-3 등록 때 초기 비밀번호 메일이 실패하면 계정을 남기는가 미정 S-FOJJKB · S-XKYOND
A · 등록 명세 · 이 목업

생성이나 초기 비밀번호 발급이 실패하면 계정을 활성화하지 않고 실패를 안내한다. 메일 실패가 여기 드는지는 적혀 있지 않다.

B · 초기화 명세처럼

발급은 유지하고 발송 실패만 기록한 뒤, 상세에서 비밀번호 초기화로 다시 보낸다.

SYSTEM-4 주소를 상세에 보이고 수정에서 고칠 수 있는가 미정 S-FOJJKB · S-BRSPGB · S-CZGHBS

등록은 우편번호·기본주소·상세주소를 받는데 상세의 표시 항목과 수정의 기본정보에는 주소가 없다. 없으면 등록한 주소를 다시 볼 수도 고칠 수도 없다. 목업은 상세와 수정 모두에 주소를 넣었다.

SYSTEM-5 플랫폼 관리자 기본 권한(PA000001)을 지울 수 있고, 대체 권한이 될 수 있는가 미정 S-JDCOAG

표본 아이디 plat_* 는 밑줄을 쓰는데 계정 입력 규칙(PL-OCJOFP)은 영문·숫자만 허용한다 — 1팀 BP 목업의 변경자 표기와 맞추려고 그대로 두었다.
