목업 권한
목업 상태
BP전용 공통코드는 BP 공통코드 관리 대상입니다

BP가 직접 추가한 상세 코드는 이 화면에서 조회하거나 변경할 수 없습니다. 해당 BP가 BP 공통코드 관리에서 등록·수정합니다.

공통코드를 저장하지 못했습니다. 잠시 후 다시 시도해 주세요.

저장 전 공통코드 정보를 그대로 두었습니다. 목록은 마지막으로 저장된 값입니다.

이미 등록된 그룹 코드입니다 — SERVICE · 서비스 (플랫폼고정). 다른 그룹 코드를 입력해 주세요.
관리 주체는 플랫폼고정·플랫폼제공 두 값만 고릅니다. 그룹 코드는 플랫폼 전체에서 하나만 쓸 수 있습니다. 권한 유형은 플랫폼 권한 관리가, 계정 상태는 플랫폼 관리자 관리가 읽습니다.
목업 표본: SERVICE 의 서비스 코드(S-CMWABV)를 뺀 그룹 코드·상세 코드 값(USE, FULL 등)은 명세에 없는 값이다.
서비스 그룹 — 상세 코드가 곧 서비스 코드입니다

코드명은 서비스명, 사용 상태는 서비스 사용 상태로 씁니다. 서비스 코드는 직접 입력하며 등록한 뒤에는 바꿀 수 없습니다. 사용중지한 서비스는 신규 메뉴 등록과 권한 부여에서만 빠지고, 이미 등록된 메뉴는 그대로 남습니다. 메뉴 관리에서 보기

플랫폼제공 그룹 — BP가 본인 BP 범위에서 고쳐 쓸 수 있습니다

여기서 고친 값은 각 BP 환경 설정의 사용 대상에 반영됩니다. BP가 따로 추가한 BP전용 코드는 이 목록에 없습니다.

상세 코드는 그룹의 관리 주체를 그대로 따르므로 관리 주체를 따로 고르지 않습니다. 같은 그룹 안에서 상세 코드는 겹칠 수 없습니다. BP가 BP 공통코드 관리에서 추가한 BP전용 상세 코드는 이 목록에 보이지 않습니다.

공통코드는 지우지 않고 사용중지로 돌린다 — 물리 삭제 기능이 없다. 그룹을 적용 서비스로 나누지 않으므로 적용 서비스 입력·검색 항목이 없다. 그룹과 상세 코드의 등록·수정 이력은 저장되지만 이 화면에서 보여 주지 않는다. 저장한 값은 해당 서비스의 BP 환경 설정 사용 대상에 반영되고, 플랫폼고정 코드는 모든 BP에 같은 값으로 간다.
