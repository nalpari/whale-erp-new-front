1팀이 만들 화면이다 — 3팀은 로그인 뒤 홈부터 받는다

manyfast [1팀공용] WHALE ERP 의 인증 및 계정 관리 명세를 그대로 옮겼다. 로그인 화면에서 닿는 여섯 갈래 — 로그인 판정, 아이디 찾기, 임시 비밀번호, 회원가입, 가입 완료, 강제 비밀번호 변경 — 를 모두 잇고, 로그인에 성공하면 3팀의 로그인 후 홈으로 넘어간다. 각 화면 위의 점선 줄은 목업 전용 상태 전환이라 오류 문구와 분기를 회의에서 넘겨 볼 수 있다.
