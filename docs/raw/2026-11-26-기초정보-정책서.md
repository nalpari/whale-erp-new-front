## 0. 이 문서를 읽는 법

- 정책 항목은 `PL-번호`로 부른다. 화면 · api · 목업은 이 번호를 근거로 적는다.
- 개념 정의서끼리 어긋나는 곳은 **8장 쟁점**에 모았다. 쟁점이 걸린 항목은 본문에 `쟁점 N` 을 달고 **추천안 기준**으로 적었다 — 확정되면 그 줄만 고친다.
- 화면정의서 v0.72 는 「마스터용 → 점포용 상속」 구조라 개념 정의서와 다르다. 구조는 개념 정의서를 따르고, 화면정의서에서는 상품 항목(옵션 SET · 다국어 · 과세 · 마케팅 · 온도 분류)만 가져온다.

## 1. 범위와 용어

| 용어 | 뜻 |
| --- | --- |
| 기초 정보 | 상품 · 카테고리 · 가격(· 자재, 이 문서 밖)의 기준 데이터. BP 가 관리한다 |
| 단위 상품 | 판매하는 상품 하나. 옵션과 **표준가격**을 가진다 |
| 상품 리스트 | 단위 상품 여러 개를 묶은 것. 점포에 통째로 적용한다 |
| 표준 카테고리 | BP 마다 하나 있는 기본 카테고리 트리(2단계) |
| 카테고리 리스트 | 상품 리스트 하나에 붙는 카테고리 트리(2단계) |
| 분류 | 카테고리 트리의 마디(1단계 · 2단계). 상품을 분류에 배정한다 |
| 표준가격 | 단위 상품에 필수로 적는 가격. 마지막 순위의 가격 |
| 일반 가격 리스트 · 프로모션 가격 리스트 | 상품 리스트에 붙는 가격표. 프로모션은 기간이 있고 일반보다 먼저 적용된다 |
| 부가서비스 | 상품을 파는 채널 — POS · KIOSK · 테이블오더 · 픽업오더 · QR오더. 공통코드 `SERVICE` 의 판매용 값 |
| 점포 적용 | 점포가 어떤 상품 · 가격을 쓰는지 정하는 것(매핑) |

이 문서 밖: 자재 정보 · 재고 차감(세트 상품의 연결 상품 구성은 PL-46 에 있다), 가격 반영 예약(쟁점 6), 부가서비스 앱 화면.

## 2. 지금 시스템에 옮기는 규칙

- **PL-1 BP 단위.** 기초 정보는 BP 하나에 한 벌이다. BP 는 화면에 들어오기 전에 정해진다 — BP · 가맹 계정은 소속 BP, 플랫폼 계정은 웨일ERP 바로가기로 고른 BP. 그래서 어떤 화면에도 BP · 본사 · 가맹점 선택칸이 없다(시설물 관리와 같다).
- **PL-2 권한.** 기초정보관리 메뉴(상품 · 카테고리 · 가격)는 **마스터 권한자**에게만 준다 — 권한 그룹에서 그 메뉴 권한을 받은 BP 마스터 · BP 관리자. 가맹 마스터 · 가맹 관리자에게는 이 메뉴를 주지 않는다. **예외**: 기초정보관리 아래 「점포 상품 관리」는 가맹 마스터 · 가맹 관리자에게도 줄 수 있다 — 맡은 점포만 보고, 판매 상태 · 품절 · 분류 사용을 바꾼다(2026-11-25 A안). 점포 권한자는 「점포 상품 관리」(PL-40)로 맡은 점포의 상품을 본다(개념 정의서 6쪽). 버튼은 메뉴 권한(조회 · 등록 · 수정 · 삭제)대로 보인다. **예외**: 점포 상품 관리의 점포 적용 · 다른 점포에 복사는 그 메뉴의 수정 권한이 있어도 BP 마스터 · BP 관리자만 고친다 — 가맹 역할은 같은 칸을 읽기만 한다(PL-40, 2026-11-25).
- **PL-3 점포 범위.** 점포에 적용할 수 있는 점포는 그 BP 의 미운영 · 운영 점포다. **본사 점포(`is_hq`)는 넣지 않는다** — 근무지용 점포라 상품을 팔지 않는다. 「전체 점포」에도 들어가지 않는다(2026-11-18 사용자 결정). 폐점 점포는 새로 적용할 수 없고, 이미 적용된 것은 그대로 둔다.
- **PL-4 가격 결정권은 본사.** 점포 적용과 가격 리스트 선택은 마스터 권한자만 한다. 가맹 역할은 판매 상태 · 품절 · 분류 사용만 바꾼다(PL-41, 쟁점 5 확정).
- **PL-5 분류 값은 공통코드.** 상품 분류(음료 · 베이커리 …) · 마케팅 분류(NEW · BEST · EVENT) · 온도 분류(HOT · ICED)는 BP 공통코드 그룹에서 가져온다. 화면에 상수표를 두지 않는다.

## 3. 기초 정보의 구조

점포는 두 방식 중 **하나만** 쓴다(개념 정의서 5쪽).

|  | 단위 상품 방식 | 상품 리스트 방식 |
| --- | --- | --- |
| 상품 | 단위 상품마다 점포를 매핑(N:N) | 상품 리스트 여러 개를 점포에 매핑, 한 시점에 노출되는 것은 하나(기본 · 기간 상품 리스트, PL-17) |
| 카테고리 | 표준 카테고리 | 그 상품 리스트에 붙은 카테고리 리스트(1:1) |
| 가격 | 표준가격 | 프로모션 → 일반 → 표준가격(PL-34) |
| 맞는 BP | 점포가 적고 모든 점포가 같은 상품을 파는 BP | 점포 · 상권마다 상품 구성이나 가격이 다른 BP |

- **PL-6 방식은 점포마다 정한다.** 처음 값은 단위 상품 방식이다. 방식을 바꾸면 이전 방식의 매핑은 그 점포에서 풀린다 — 바꾸기 전에 확인창으로 「단위 상품 매핑 N건이 풀립니다」처럼 수를 보인다.
- **PL-7 카테고리 · 가격은 상품을 따라간다.** 카테고리 리스트 · 가격 리스트는 점포에 직접 매핑하지 않는다. 상품 리스트를 통해 정해진다.

## 4. 상품 정보

### 단위 상품

- **PL-10 등록 · 수정.** 단위 상품과 옵션을 등록 · 수정 · 조회한다. **표준가격은 필수**(0 이상 원 단위 정수, 0 이면 무료).
- **PL-11 항목.** 상품 유형(필수, 단일 상품 · 세트 상품, 기본 단일 — PL-46) · 상품명(필수) · 다국어 이름(영어 · 중국어 간체 · 번체 · 일본어, 선택) · 상품 분류(공통코드) · 설명(필수) · 마케팅 분류 · 온도 분류(여럿 고름) · 과세 구분(과세 · 면세 · 비과세, 과세는 가격에 VAT 포함) · 목록 이미지 1장 · 표준가격 · 노출 순서(비우면 맨 뒤) · 상품 코드(자동 채번, 변경 불가).
- **PL-12 옵션.** 옵션 SET 여러 개 · SET 안에 옵션 여러 개. 옵션은 「옵션 상품 관리」에 등록한 **옵션 상품**으로 넣는다(B안 확정, 2026-11-25 — 옵션 셋트를 따로 관리하는 A안은 접었다).
  - 옵션 SET: 이름(필수) · 필수선택 · 다중선택 · 노출 순서 · 상태. SET 은 단위 상품마다 만든다.
  - 옵션: 옵션 상품(PL-44) · 추가 가격(PL-45) · 수량 입력 · 기본 선택 · 상태.
  - 옵션 상품: 옵션 상품명 · 옵션 코드(OP+6자리, 자동 채번) · 추가 가격(기본값) · 상태. 단위 상품과 따로 있는 목록이라 단위 상품 목록 · 상품 리스트 · 카테고리에 나오지 않는다.
  - 옵션 단위로 상태를 둘 수 있고, 상태에 따라 부가서비스에 옵션이 보인다(개념 정의서 5쪽).
- **PL-13 상태.** 활성 · 비활성. 새로 등록한 상품은 **비활성**이다. 활성으로 바꿔야 부가서비스에 보일 수 있다(PL-38).
- **PL-14 삭제.** 한 번도 활성화한 적 없는 상품만 실제로 지운다. 한 번이라도 활성화했던 상품은 지울 수 없고 비활성으로 바꾼다 — [삭제]는 막힌 버튼과 말풍선 「판매한 적이 있는 상품은 삭제할 수 없습니다. 비활성으로 바꿔 주세요.」(`쟁점 4`). 옵션은 옵션 상품이라(PL-12) 단위 상품이 다른 상품의 옵션으로 쓰이는 일은 없다 — 옵션 상품의 삭제는 옵션 상품 관리에서 막는다.
- **PL-15 단위 상품의 점포 매핑.** 단위 상품 방식 점포만 고를 수 있다(N:N). 매핑하면 그 점포의 부가서비스에 보일 수 있고, 풀면 보이지 않는다. 단위 상품 등록 · 수정 · 상세에서 매핑하고, 점포 고르기는 BP 관리자 등록의 대상 점포와 같은 방식(찾기 · 일괄 검색 · 선택한 점포)이다(2026-11-24).
- **PL-44 옵션 상품 고르기 · 새 옵션 등록.** 단위 상품 등록 · 수정의 옵션 줄은 자동완성 선택칸이다 — 이름을 치면 옵션 상품 관리에 있는 옵션 상품(이름 · 옵션 코드 · 추가 가격)이 뜨고 골라 넣는다(찾기 팝업 없음). 맞는 이름이 없으면 「「입력한 이름」 새 옵션으로 등록」을 고를 수 있고, 단위 상품을 **저장할 때** 그 이름과 줄에 적은 추가 가격(비우면 0)으로 옵션 상품 관리에 새 옵션 상품이 등록된다 — 옵션 코드는 그때 채번, 상태는 활성. 저장하지 않으면 만들지 않는다. 이름은 공백 · 대소문자를 빼고 같으면 같은 옵션 상품으로 보고 새로 만들지 않는다(2026-11-25).
- **PL-45 옵션 추가 가격은 단위 상품에서 바꿀 수 있다.** 옵션 상품을 고르면 그 추가 가격을 불러오고, 단위 상품마다 바꿀 수 있다 — 바꾼 값은 그 단위 상품의 SET 에만 쓴다. 화면은 칸 아래에 「기본 N원」을 보인다. 옵션 상품 관리에서 추가 가격을 바꾸면 단위 상품에서 따로 바꾸지 않은 줄에만 반영된다(잠정 — 문의 Q3). 이름 · 상태 변경은 모든 단위 상품에 바로 반영된다(2026-11-25).
- **PL-46 상품 유형 · 연결 상품.** 단위 상품은 「단일 상품」 또는 「세트 상품」이다(등록할 때 고름, 2026-11-25). 세트 상품만 단일 상품을 연결 상품으로 넣어 구성하고, 연결 상품 후보는 **단일 상품만**이다(세트 안에 세트를 넣지 않는다). 세트 상품은 연결 상품이 1개 이상 있어야 저장된다.
  - 유형 바꾸기: 단일 → 세트는 다른 세트에 연결된 상품이면 막는다(「세트 상품 N개에 연결된 상품입니다」). 세트 → 단일은 연결 상품을 모두 빼야 바꾼다 — 연결 상품별 옵션 묶음도 함께 빠진다.
  - 단위 상품 목록은 「상품 유형」 열(단일 상품 · 세트 상품)을 두고 상품 유형으로 거른다. 상세는 상품 유형 줄을 보인다.
  - 연결 상품: 수량 칸은 두지 않는다 — 같은 상품이 두 개 들어가면 두 번 연결한다(예: 아메리카노 · 아메리카노 · 치즈케익, 2026-11-25). 등록 · 수정에서 등록된 단위 상품을 자동완성으로 고르고(새 상품은 만들지 않는다, 세트 상품은 후보에서 빠진다), 상세에서 본다.
  - 연결해도 다른 상품 정보(가격 · 옵션 · 카테고리 · 점포 매핑 · 노출)는 바뀌지 않는다. 나중에 재고 관리에서 이 상품을 팔면 연결한 상품을 연결한 수만큼 함께 차감할 때만 쓴다.
  - 고른 연결 상품에 옵션 SET 이 있으면 「옵션도 추가할까요?」를 물어 SET 을 골라 그 연결 상품의 옵션 묶음(PL-47)에 **복사**한다 — 복사한 뒤에는 이 상품의 SET 이라 따로 고치고, 연결 상품의 옵션을 바꿔도 따라가지 않는다. 「옵션 없이 연결」도 되고, 나중에 묶음의 [옵션 가져오기]로 다시 가져올 수 있다.
- **PL-47 연결 상품별 옵션.** 연결 상품이 있는 상품의 옵션 구성은 「세트 공통」과 「연결 상품별 묶음」으로 나눈다(2026-11-25).
  - 세트 공통: 세트 전체에 한 번 고르는 옵션(포장 · 세트 업그레이드 등). 연결 상품이 없는 상품은 이 칸만 있다(지금 옵션 구성과 같다).
  - 연결 상품별 묶음: 연결한 줄 하나에 묶음 하나. 같은 상품을 두 번 연결하면 묶음도 둘이고 연결한 순서로 번호를 붙인다(「아메리카노 1」 · 「아메리카노 2」). 묶음마다 옵션 SET 을 따로 두고 더하거나 고친다 — 그래서 주문할 때 아메리카노 하나마다 옵션을 따로 고른다. 연결 상품을 빼면 묶음도 빠지고 번호를 다시 매긴다.
  - 가격: 세트 가격은 이 상품의 표준가격(가격 리스트 포함)이고 연결 상품의 가격은 쓰지 않는다. 옵션 추가 가격은 고른 횟수만큼 더한다.
  - 주문 · 외부 POS 가 연결 상품별 옵션을 받는지는 문의 Q10, 옵션의 재고 차감은 Q11.

### 상품 리스트

- **PL-16 등록 · 수정.** 이름 · 상태(활성 · 비활성) · 담은 단위 상품. 리스트 안에서 상품을 넣고 뺀다. 한 상품이 여러 리스트에 들어갈 수 있다(N:N).
- **PL-17 점포 매핑.** 리스트 하나를 여러 점포에 매핑하고, 점포 하나도 여러 리스트에 매핑될 수 있다(N:N). 한 시점에 점포에 노출되는 리스트는 하나다. 매핑을 풀면 그 점포에서 리스트의 상품이 보이지 않는다. 매핑과 노출은 나눠 정한다(2026-11-25).
  - **매핑**: 상품 리스트 상세의 「적용 점포」에서 이 리스트를 **쓸 수 있는** 점포를 고른다. 기간 · 가격 리스트는 여기 없다. 점포 고르기는 단위 상품 수정의 적용 점포와 같다(찾기 · 일괄 검색 · 선택한 점포). 점포 하나가 여러 리스트에 매핑될 수 있다.
  - **노출**: 점포 상품 관리에서 그 점포에 매핑된 리스트 가운데 기본 상품 리스트 하나를 정하고, 다른 리스트를 기간 상품 리스트로 걸어 둔다(기간 동안 바꿔 끼움). 한 시점에 노출되는 리스트는 하나다 — 확정 전(문의 Q9).
- **PL-18 상품을 넣고 빼면 가격 리스트도 따라간다.** 넣으면 그 상품 리스트의 모든 가격 리스트 상세에 같은 상품 줄이 **빈 칸으로** 보인다 — 가격 데이터를 만들어 넣지 않는다. 관리자가 가격을 적어 저장해야 그 상품의 가격 데이터가 생긴다. 그 전에는 일반은 표준가격, 프로모션은 일반 가격이 적용되고(PL-33), 화면은 일반 가격 리스트 상세의 「가격」 칸에 회색 「표준가 N 적용」을 보인다. 표준가격을 값으로 채워 두면 실제로 정한 가격인지 알 수 없어서다(2026-11-25). 빼면 가격 리스트에서도 빠지고 카테고리 리스트의 배정도 풀린다.
- **PL-19 삭제.** 점포에 매핑된 리스트는 지울 수 없다 — 「N개 점포가 쓰는 리스트입니다. 점포 적용을 먼저 바꿔 주세요.」 매핑이 없으면 논리 삭제하고, 붙은 카테고리 리스트 연결 · 가격 리스트도 함께 지운다(`쟁점 8`).

## 5. 카테고리 정보

- **PL-20 2단계.** 카테고리 트리는 1단계 · 2단계까지다. 상품은 어느 단계의 분류에도 배정할 수 있다.
- **PL-21 분류 항목.** 분류명(필수) · 상태(사용 · 미사용) · 노출 순서 · 분류 코드(자동 채번). 미사용 분류에도 상품을 배정할 수 있다(나중에 켜려고 준비).
- **PL-22 배정.** 분류마다 상품을 배정한다. 한 상품을 여러 분류에 둘 수 있다(N:N). 분류에 배정하지 않은 상품은 부가서비스에 보이지 않는다 — 단, 점포가 「카테고리 사용」을 끈 경우는 뺀다(`쟁점 3`).

### 표준 카테고리

- **PL-23 BP 마다 하나.** BP 가 생길 때 빈 표준 카테고리가 만들어진다. 표준 카테고리 자체는 지울 수 없고, 그 안의 분류는 지울 수 있다(배정도 함께 지워진다).
- **PL-24 배정 후보.** 그 BP 의 모든 단위 상품.

### 카테고리 리스트

- **PL-25 상품 리스트와 1:1.** 카테고리 리스트는 상품 리스트 하나에 붙는다. 배정 후보는 그 상품 리스트에 담긴 상품뿐이다.
- **PL-26 등록 · 수정.** 리스트 이름 · 상태 · 트리(분류)를 관리한다.
- **PL-27 삭제는 실제 삭제.** 리스트나 분류를 지우면 상품 배정도 지워진다. 지우기 전에 「배정된 상품 N개의 배정이 풀립니다」를 확인창으로 보인다.

## 6. 가격 정보

- **PL-30 표준가격.** 단위 상품에 적는다(PL-10). 가격 리스트를 쓰지 않거나, 리스트에 그 상품 가격이 없으면 표준가격이 적용된다.
- **PL-31 가격 리스트 두 종류.** 일반 · 프로모션. 가격 리스트는 상품 리스트 하나에 붙고(상품 리스트 1 : 가격 리스트 N), 그 상품 리스트의 모든 상품 가격을 다룬다.
  - **등록**(2026-11-25): 등록 화면 하나에서 가격 리스트 이름 · 유형(일반 · 프로모션) · 상품 리스트 · (프로모션은 기간) · 상품 가격을 한 번에 넣는다. 상품 리스트를 고르면 그 리스트의 상품이 가격 표에 펼쳐지고, 체크한 상품에 표준가격 기준 정액 · 정률 · 지정가를 일괄로 채울 수 있다. 상품 리스트 상세의 [가격 리스트 등록]은 그 리스트를 미리 고른다.
  - 묶인 상품 리스트는 등록한 뒤 바꿀 수 없다. 상품 리스트 상세의 「가격 리스트」 묶음이 묶인 가격 리스트를 표로 보인다(유형 · 이름 · 기간 · 상태 · 상품 수 · 고른 점포).
- **PL-32 부가서비스별 가격.** 상품마다 「기본 가격」 하나와 부가서비스별 칸을 둔다. 부가서비스 칸을 비우면 기본 가격을 따른다. 프로모션은 문서에 명시돼 있고, 일반 가격 리스트에도 같은 모양을 쓴다(`쟁점 2` · 문의 Q7).
- **PL-33 빈 가격과 0.** 0 은 무료 판매다. 빈 칸은 「그 리스트에 가격 없음」이라 다음 순위로 넘어간다 — 일반 리스트의 빈 칸은 표준가격(쟁점 1 확정 · 2026-11-18), 프로모션의 빈 칸은 일반 리스트 가격. 빈 칸으로는 판매를 멈추지 않는다 — 판매를 멈추려면 상품을 비활성으로 바꾸거나 점포에서 품절 · 판매 중지로 둔다. 화면은 일반 리스트의 빈 칸에 회색으로 「표준가 4,500 적용」처럼 실제로 적용되는 가격을 보인다.
- **PL-34 적용 순서.** 부가서비스마다 **프로모션 가격 리스트 → 일반 가격 리스트 → 표준가격** 순으로, 앞 순위에 가격이 있으면 그것을 쓴다(개념 정의서 10쪽).
- **PL-35 프로모션 기간.** 프로모션 리스트는 시작일 · 종료일(필수)을 가진다. 기간 밖에는 매핑돼 있어도 적용되지 않고, 끝나면 자동으로 쓰이지 않는다. 상태는 기간으로 셈한다 — 대기(시작 전) · 진행 중 · 종료.
- **PL-36 점포의 선택.** 상품 리스트 방식 점포는 그 상품 리스트에 붙은 가격 리스트 가운데 기본 · 기간 상품 리스트**마다 일반 하나 · 프로모션 하나**까지 고른다(둘 다 비워도 된다 — 그러면 표준가격). 고르는 사람은 마스터 권한자다(PL-4, 개념 정의서 14번째 슬라이드 「가격 리스트 매핑(가격 1,2 중 선택)」이 BP 관리자 칸). **점포 상품 관리에서만** 고른다 — 기본 · 기간 상품 리스트마다 그 리스트에 붙은 가격 리스트 가운데서(2026-11-25 A안). 상품 리스트 상세의 적용 점포에는 가격 칸이 없다.
- **PL-37 수정 · 이력 · 삭제.**
  - 가격 리스트 · 표준가격의 상품별 가격을 고칠 수 있다. 고친 값은 바로 적용된다.
  - **모든 가격 변경을 이력으로 남긴다** — 상품 · 리스트 · 부가서비스 · 이전 값 · 새 값 · 바꾼 사람 · 시각. 이력은 지우지 않는다(개념 정의서 13쪽 「히스토리 관리 중요!」).
  - 가격 리스트 삭제는 논리 삭제다. 그 리스트를 고른 점포는 자동으로 선택이 풀리고 다음 순위 가격이 적용된다 — 지우기 전에 「N개 점포가 이 리스트를 쓰고 있습니다」를 확인창으로 보인다.

## 7. 노출 조건과 점포 운영

- **PL-38 부가서비스 노출 조건.** 상품이 점포의 부가서비스에 보이려면 모두 맞아야 한다.
  1. 상품이 활성이고, 상품 리스트 방식이면 그 리스트도 활성
  2. 점포에 매핑돼 있음(단위 매핑 또는 상품 리스트)
  3. 적용 가격이 있음(PL-34 — 표준가격이 필수라 늘 있다)
  4. 그 점포가 쓰는 카테고리의 분류에 배정돼 있음(점포가 카테고리를 끄면 빼고)
  5. 점포의 그 부가서비스 판매 상태가 「판매」(PL-41)
- **PL-39 안 보이는 이유를 보인다.** 관리자 화면은 점포마다 「안 보이는 상품 N건」과 상품별 이유(「비활성」 · 「카테고리 미배정」 · 「판매 중지(KIOSK)」 등)를 보여 주고, 고칠 화면으로 바로 보낸다(점포 상품 관리 — PL-40).
- **PL-40 점포 상품 관리.** 점포 하나를 골라 그 점포의 상품 · 카테고리 · 최종 가격(어느 리스트에서 왔는지 꼬리표)을 보고, 점포 설정(PL-41)을 바꾼다. 따로 「점포 적용 관리」 메뉴를 두지 않는다(쟁점 7 확정, 2026-11-25).
  - **점포 적용**: 같은 화면 위쪽에서 점포 옆에 상품 방식(단위 상품 · 상품 리스트)을 고르고, 상품 리스트면 기본 상품 리스트 · 기간 상품 리스트와 리스트마다 일반 · 프로모션 가격 리스트를 고른다(팝업 없이 화면에서 바로). 고를 수 있는 리스트는 그 점포에 매핑된 것뿐이다(PL-17). 방식을 바꾸면 저장 전에 확인창으로 풀리는 매핑 수를 알린다(PL-6).
  - 상품 리스트의 내용(담는 단위 상품)은 여기서 고치지 않는다 — 여러 점포가 같은 리스트를 쓰므로 상품 정보 관리에서 고친다.
  - 점포 적용 · 복사(PL-43)는 BP 마스터 · BP 관리자만 고치고, 가맹 마스터 · 가맹 관리자는 맡은 점포를 읽기만 한다. 판매 상태 · 품절 · 분류 사용(PL-41)은 가맹 역할도 바꾼다.
- **PL-41 점포 설정.** 점포 단위로 바꿀 수 있는 것은 셋뿐이다.
  - 상품 · 옵션의 부가서비스별 판매 상태(판매 · 판매 중지)
  - 품절 — 모든 부가서비스에 같이 적용. 품절은 보이되 주문할 수 없다
  - 카테고리 분류별 사용 여부 — 점포에 걸린 상품 리스트마다 따로 정한다. 화면은 상품 리스트를 선택칸으로 골라 그 리스트의 분류 트리를 켜고 끈다(리스트가 많아도 되게, 2026-11-25)
- **PL-42 점포 설정은 기초 정보 수정에 덮이지 않는다.** 마스터가 상품 · 카테고리를 고쳐도 점포가 정한 판매 상태 · 품절 · 분류 사용 여부는 그대로다(개념 정의서 14쪽). 상품을 비활성으로 바꾸면 점포 설정과 상관없이 보이지 않는다.
- **PL-43 다른 점포에 복사.** 점포 상품 관리에서 지금 점포에 저장된 설정을 기준으로 고른 점포들에 같은 설정을 넣는다(2026-11-25).
  - 점포 적용(상품 방식 · 상품 리스트 · 가격 리스트)은 늘 복사하고, 카테고리 분류 사용 여부 · 상품 판매 상태 · 품절은 골라서 복사한다.
  - 대상 점포는 BP 관리자 등록의 대상 점포와 같은 방식으로 고른다. 기준 점포 · 본사 점포 · 폐점 점포는 후보에 없다.
  - 대상 점포의 기존 설정은 덮어쓴다. 단위 상품 방식 점포는 단위 상품 매핑이 풀린다(PL-6).
  - 대상 점포에 있는(매핑된) 상품 리스트 · 단위 상품에만 적용한다 — 예: 기준 점포의 기간 상품 리스트가 대상 점포에 매핑되지 않았으면 그 줄은 빠진다. 다 적용되면 토스트로, 일부만 적용된 점포가 있으면 화면 위 안내 띠로 점포마다 적용하지 못한 것을 알린다 — 띠는 다음 저장 · 복사까지 남는다.
  - BP 마스터 · BP 관리자만 쓴다.

## 10. 영문 식별자 초안

저장소 네이밍 규칙(`okf/conventions/naming.md`)의 대응표에 더할 초안이다. 「메뉴」는 시스템 메뉴(`menu_code`)와 겹쳐 상품을 `product` 로 부른다.

| 표준 표기 | 영문 식별자 | 비고 |
| --- | --- | --- |
| 단위 상품 · 상품 코드 | `product` · `product_code` | 상품 유형 `product_type`(`SINGLE` / `SET`, PL-46), 표준가격 `standard_price_amount`, 상태 `is_active`, 활성화 이력 `first_activated_at`(PL-14) |
| 옵션 SET · 옵션 | `product_option_set` · `product_option` | `is_required` · `is_multiple` · `option_product_id` · `extra_price_amount` |
| 옵션 상품 · 옵션 코드 | `option_product` · `option_product_code` | 기본 추가 가격 `extra_price_amount`. 단위 상품 줄의 바꾼 값은 `product_option.extra_price_amount`(PL-45) |
| 연결 상품 | `product_component` | `product_id` · `component_product_id` · `display_order`(PL-46, 수량 없이 연결 하나가 한 개). 옵션 SET 은 `product_option_set.product_component_id`(비면 세트 공통, PL-47) |
| 상품 리스트 | `product_list` · `product_list_item` |  |
| 카테고리 리스트 · 표준 카테고리 | `category_list` · `is_standard` | 표준 카테고리는 `is_standard = true` 인 카테고리 리스트 한 줄 |
| 분류 · 상품 배정 | `category` · `category_product` | `parent_category_id`, `depth`(1 · 2) |
| 가격 리스트 · 유형 | `price_list` · `price_list_type`(`GENERAL` / `PROMOTION`) | 기간 `start_date` · `end_date` |
| 가격 줄 | `price_list_item` | `base_price_amount` + 부가서비스별 `service_code` · `price_amount` |
| 가격 변경 이력 | `price_change_history` | 이전 · 새 값, `changed_by` |
| 점포 적용 | `store_master_data_setting` | `product_source_type`(`UNIT` / `LIST`) |
| 점포 상품 리스트 | `store_product_list` | 매핑 한 줄(`store_id` · `product_list_id`). 노출은 `list_role`(`DEFAULT` / `PERIOD`, 비면 매핑만) · 기간 `start_date` · `end_date` · `general_price_list_id` · `promotion_price_list_id`(PL-17 · PL-36) |
| 점포 분류 사용 | `store_category_setting` | 리스트별 분류 `category_id` · `is_used`(PL-41) |
| 점포 상품 설정 | `store_product_setting` | 부가서비스별 판매 상태 · `is_sold_out` |
