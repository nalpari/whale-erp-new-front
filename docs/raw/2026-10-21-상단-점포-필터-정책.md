# 상단 점포 검색 필터 — 점포 선택 시 동작 (2026-10-21)

출처: 기획 정책 변경(사용자 전달, 2026-10-21). 기존 정책(범위 변경 시 홈으로 이동 — okf/home.md 범위 선택기, STAFF-12)을 대체한다.
(front 메모: 바로 앞 구현은 2026-10-20 의 「점포 검색 필터가 있는 메뉴에서만 그 목록으로 이동」이었다.)

## 이동
- 상단 점포 검색 필터에서 점포를 선택(변경)하면 **현재 보고 있는 메뉴의 목록 화면**으로 무조건 이동한다.
- 현재 화면이 목록이 아니어도(상세 · 등록 · 수정) 같은 메뉴의 목록 화면으로 이동한다.
- 기존 정책(범위 변경 시 홈으로 이동)을 대체한다.

## 목록 화면의 검색 처리
- 이동한 목록 화면에 **다중 점포 검색 필터**가 있는 경우
  - 상단 필터에서 선택한 점포가 목록 검색 영역의 점포 필터에 표시된다.
  - 별도의 검색 버튼 클릭 없이 해당 점포 조건으로 바로 검색된다.
- 다중 점포 검색 필터가 없는 경우
  - 목록 화면으로 이동만 하고, 기본 검색 조건으로 조회한다.

## 공통
- 이동 시 목록 화면의 다른 검색 조건(기간, 상태 등)은 초기값으로 시작한다.
- 상단 필터에서 '전체'를 선택하면 목록의 점포 필터는 비운 상태(전체)로 검색한다.
- 화면은 선택 점포를 표시·검색 조건으로만 사용한다. 점포 데이터 권한은 api 가 요청마다 다시 판정한다.

## 구현 메모 (front, 2026-10-21)
- 메뉴가 아닌 화면(홈 등)에서는 이동하지 않고 범위만 바꾼다(이동할 「메뉴의 목록」이 없다).
- 헤더는 이동할 때 범위를 주소에 `?scope=DIRECT · FRANCHISE · STORE:<id>` 로 싣는다(전체는 메뉴 링크에는 싣지 않고, 범위를 「전체」로 바꿔 이동할 때만 `scope=ALL`). 점포 검색 필터가 있는 목록만 읽고, 없는 목록은 무시한다 — 어느 메뉴에 필터가 있는지 적어 두는 목록은 두지 않는다(메뉴 주소 · 코드는 환경마다 다를 수 있다).
- 직영 · 가맹 전체는 점포 id 로 풀지 않고 점포유형 조건으로 api 에 보낸다(주소 · 요청 길이).
