## 공통 규칙 (모든 화면)

- 기준 파일: `docs/mockup/stores/facilities.html` · `facilities-detail.html` · `facilities-new.html` 의 뼈대를 그대로 쓴다 — `<body data-root="../" data-page="master" data-sub="master/<부모>.html">`, 맨 위 HTML 주석(화면 · 라우트 · 1팀 · 2차, 기준 PL 번호, 그린 이유), `.titlebar`(제목 · `badge--warn` 「1팀 작업」 · 오른쪽 `filters__count mono` 「2차 · /라우트」), `.content` 안 `.demo` 점선 줄로 목업 상태 전환(`data-demo="<id>"` + `data-state`, 대상 요소 `data-show="상태 …"` + 기본 아닌 것은 `hidden`), `.panel` · `.tbl` · `.kv` · `.band` · `.badge` · `.modal` · `.tabs[data-tabs]` + `[data-panel]`, 끝에 `<script src="../assets/app.js"></script><script src="../assets/auth.js"></script>`.
- 화면정의서 버튼(`*.screen-def.html`)은 이번에 두지 않는다(나중에 만든다).
- 문구 · 디자인은 DESIGN.md 를 따른다: 「최종수정」, 빈 문구 「등록된 …이 없습니다.」 / 「조건에 맞는 …이 없습니다.」, [목록]은 primary, 확인창 문구는 주어 · 동사를 갖춘 문장, 금액은 `mono` 와 천 단위 쉼표 + 「원」.
- BP 선택칸 · 본사/가맹점 선택칸은 어디에도 두지 않는다(PL-1). 검색 조건 패널 머리 오른쪽에 `BP <b>㈜한강상회 · BP000017</b>` 만.
- 점포를 고르는 곳에서는 본사 점포를 빼고(PL-3), 폐점 점포는 새로 고를 수 없다.
- 목업 로그인 사용자는 BP 마스터 정하윤. 권한 데모 줄(`data-demo-key="role"`, `data-show-role="edit"`)은 목록 화면에만.
- 용어: 「단위 상품」 「상품 리스트」 「표준 카테고리」 「카테고리 리스트」 「분류」(1단계 · 2단계) 「표준가격」 「일반 가격 리스트」 「프로모션 가격 리스트」 「부가서비스」 「점포 매핑」. 「메뉴」를 상품 뜻으로 쓰지 않는다.
- 상태 배지: 상품 · 상품 리스트 활성 `badge--ok` 「활성」 / 비활성 `badge--quiet` 「비활성」. 분류 사용 `badge--ok` 「사용」 / 미사용 `badge--quiet`. 프로모션 대기 `badge--quiet` · 진행 중 `badge--info` · 종료 `tag`. 품절 `badge--risk` 「품절」.

- **상품 탭**: 표: 상품(이미지 · 이름 · 분류) · 노출(「노출」 ok / 「안 보임 · 카테고리 미배정」 quiet + 이유 PL-38) · 적용 가격(가격 + 출처 꼬리표 「프로모션」 「일반」 「표준」, PL-34) · 품절 토글(모든 부가서비스 공통) · 부가서비스별 판매 상태(POS · KIOSK · 테이블오더 · 픽업오더 · QR오더 작은 토글 5개) · [옵션] 펼침 → 옵션 줄마다 같은 부가서비스별 토글. 바꾸면 바로 저장 · 토스트 「판매 상태를 바꿨습니다.」. note: 「본사가 상품 정보를 고쳐도 여기서 정한 판매 상태 · 품절은 그대로입니다.」(PL-42).
- **카테고리 분류 탭**: 이 점포가 쓰는 카테고리의 분류 트리 + 분류마다 「이 점포에서 사용」 토글(PL-41). 위에 쟁점 3 꼬리표(「카테고리를 통째로 끄기 — Q4 답변 대기」).
- 데모 상태: 상품 리스트 방식(을지로) · 단위 상품 방식(서초점 — 카테고리는 표준 카테고리, 가격은 모두 표준) · 적용된 상품 없음(청담점처럼 비면 「이 점포에 적용된 상품이 없습니다.」 + 본사 문의 안내).
