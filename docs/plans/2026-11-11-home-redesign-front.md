# 로그인 후 홈 개편 — 관리자 웹 (WHALEERP-665)

근거: 2026-11-11 재영 결정, 운영 정책 v278 HOM-03~10, 용어집(확인 필요(홈) · 점포별 확인 필요 · 점포 하나 화면 · 경고 밴드 없앰). 시안은 화면 구성만 참고한다(매출 · 지출 · 구독은 2차라 넣지 않는다). api 는 같은 일감의 api PR(점포별 미출근 · 오늘 TO-DO · 미운영 수 · 전체 반환 · `dueInDays`)을 쓴다.

## 바꾸는 것

1. **점포 하나 화면을 없앤다**(HOM-05). 점포를 하나 고르거나 가맹마스터 · 가맹관리자여도 같은 틀에 그 점포 값만 보인다. `one-store-screen.tsx` · `one-store-view.ts` · 그 테스트를 지운다. 근무스케줄 · 직원 정보 표 · 직원 급여 카드는 홈에서 빠진다.
2. **화면 순서**: 공지 띠 → 수치 카드 → 점포별 현황(7) · 확인 필요(5) 나란히. 공지 띠는 점포 하나 화면에 있던 것을 옮긴다(게시일 최신 3건, `latestNotices` 는 `home-view.ts` 로).
3. **경고 밴드를 없앤다**(HOM-04). 확인 필요의 「계약 갱신 예정」 줄에 「새 근로계약서 초안 없음 · 종료 D-N」을 적고 7일 이내면 빨간색이다. 새 계약은 그 줄로 간 근로계약 목록에서 쓴다.
4. **이름**: 「처리 대기」 → 「확인 필요」, 점포별 「미조치」 열 → 「확인 필요」. 빈 안내는 「확인할 일이 없습니다.」
5. **본사 ATT-30 안내 문구를 뺀다**(HOM-09) — 카드 · 표 아래의 「동의하지 않은 가맹 직원은 … 세지 않습니다」. 세는 기준은 api 그대로다.
6. **수치 카드**(HOM-10): 운영 점포(아랫줄 「직영 N · 가맹 N」, 미운영이 있으면 「· 미운영 N」) · 재직 직원 · 오늘 출근 · 내 문의 · 오늘 TO-DO(「완료 / 전체건 완료」, 아랫줄 「대기·진행 중 N건」, TO-DO 목록 오늘로 이동). 권한 없는 카드는 숨기고 남은 카드가 칸을 나눈다.
7. **점포별 현황 표**(HOM-06): 운영 점포 모두, 확인 필요 많은 순. 열은 점포명 · 유형 · 재직 직원 · 미체결 계약 · 오늘 출근 · 미출근 · 오늘 TO-DO · 확인 필요. 넘치면 표 안에서 스크롤한다. 권한이 없어 값이 없는 열은 숨긴다(HOM-09). 표 아래에 「운영 중인 점포만 보입니다. 미운영 점포의 건은 확인 필요에만 셉니다.」
