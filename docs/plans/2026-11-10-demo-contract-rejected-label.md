# 데모 알림 문구의 「거부」를 「서명 거절」로

근거: 2026-11-10 재영 승인(기획 세션 header 전달). 화면설계서 그림 SCR-ADM-031 · 059 · 061 에 남은 옛 표기를 고친다.

- `docs/demo` 의 근로계약 서명 거절 알림 이름과 문구만 고친다. 템플릿 코드 표의 이름은 함께 바꿔야 이어진다.
- 근로계약 상태가 아닌 「거부」(동의 거부 등)와 파일 머리 주석은 두고, 앱 코드 · api 기본 문구는 건드리지 않는다.
- 검증: `docs/demo/build.mjs` 로 html 을 다시 만들고 바뀐 파일이 대상뿐인지 본다.
