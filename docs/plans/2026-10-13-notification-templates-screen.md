## 화면

| 주소 | 화면 |
|---|---|
| `/platform/notification-templates?channel=` | 목록. 채널 탭 넷(운영 알림 · 앱 푸시 · 메일 · 알림톡), 건수, 등록 버튼 |
| `/platform/notification-templates/new` | 등록 |
| `/platform/notification-templates/[id]` | 수정 |

- **메뉴:** `platform-menus.ts` 시스템관리에 「알림 템플릿 관리」를 공통코드 관리 다음에 한 줄 더한다(NOTIFY-7, 1팀 전달 사항 14번 — 이 파일은 공통 헤더가 나오면 지우는 임시 파일).
- **목록 칸:** 템플릿 이름(1팀 메일 8종은 「1팀」 꼬리표) · 템플릿 코드 · 받는 사람 · 제목 · 최근 수정(고친 적 없으면 「기본 문구」) · 사용 여부. 알림톡 탭은 제목 대신 카카오 템플릿 코드 · 본문 요약. 사용 안 함 줄은 흐리게. 쪽 나눔은 다른 목록과 같이 20 · 50 · 100.
  - 「받는 사람」은 데이터에 없다 — 채널로 정한다(운영 알림 「관리자」, 앱 푸시 「직원」, 알림톡 「직원(가입 전 포함)」, 메일은 템플릿마다 달라 「-」). 데이터 칸이 필요하면 쟁점으로 올린다.
- **수정 · 등록 화면(같은 틀):** 왼쪽 — 사용 스위치, 발송 채널, 템플릿 이름, 템플릿 코드, 수신 설정 묶음(앱 푸시만), 카카오 템플릿 코드(알림톡만), 제목(알림톡 제외), 변수 단추 + 본문, 변수 목록 표(이름 · 표시 이름 · 필수 · 예시 값 · 버튼 링크(NOTIFY-20) · 삭제, 줄 추가). 오른쪽 — 채널 모양 미리보기(예시 값으로 채움), 변경 이력(수정만).
  - 등록에서 채널을 고르면 코드 접두(NTF_ · PUSH_ · EMAIL_ · TALK_)를 채운다. 등록 · 수정 모두 저장 전에 「저장하시겠습니까?」 확인창을 띄운다(2026-10-13 재영). 수정에서 코드를 바꿨으면 같은 확인창에 「발송 코드에서 이 템플릿 코드를 쓰고 있으면 함께 바꿔야 합니다」를 덧붙인다.
  - 앱 푸시는 글자 수를 세어 넘으면 빨갛게 하고 저장을 막는다. 알림톡 본문 위 「카카오 검수를 받은 문구와 한 글자라도 다르면 발송되지 않습니다. 검수를 받은 뒤 고쳐 주세요.」. 메일 본문 위 「일반 글로 씁니다. 머리 · 꼬리와 버튼은 공통 메일 틀이 붙입니다.」
  - 기본 문구로 되돌리기: 기본값이 있는 템플릿에만(NOTIFY-17 · 18), 확인창 「기본 문구로 되돌리시겠습니까?」. 알림톡이면 카카오 템플릿 코드는 그대로라 「검수받은 본문과 맞는지 확인해 주세요」를 덧붙인다(2026-10-13 재영). 되돌려도 저장하지 않은 이름 · 코드 입력은 지우지 않는다.
  - 검사는 api 가 최종으로 하고, 화면도 같은 규칙(목록에 없는 변수, 빠진 필수 변수, 글자 수)을 저장 전에 띄운다. 그사이 누가 고쳤으면(409) 「다른 사람이 먼저 고쳤습니다. 새로 불러온 뒤 다시 저장해 주세요」.
- **탭:** 공통 컴포넌트에 없다. 데모 `extra.mjs` 의 `tabs` 모양을 이 화면 폴더 안에 둔다(공통 컴포넌트는 고치지 않는다).
- **권한:** 플랫폼 마스터 · 플랫폼 관리자만. api 가 403 이면 「알림 템플릿을 볼 권한이 없습니다」.
