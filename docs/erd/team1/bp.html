BP 마스터 계정 관리

플랫폼 사용자가 BP 마스터 계정을 등록·조회·수정·삭제하는 영역이다. BP 마스터 계정 하나가 조직의 뿌리이며, 소속 관리자와 점포가 이를 참조한다.

개요인증·계정점포관리BP 관리환경설정 & 시스템관리

중심

BP 코드가 조직의 뿌리다

  • BP 코드가 BP 조직 정보를 관리한다
  • 가입경로는 회원가입과 플랫폼등록 두 가지다
  • BP 상태 변경 시 소속 계정과 점포도 영향받는다

BP 코드와 소속

  • BP 코드 1건에 소속 관리자 N명이다
  • 변경 이력은 상호명·상태·사업자정보 등을 기록한다

3팀 참조

  • 계정(accounts)과 직원 레코드(staff_members)는 3팀 소유다
  • 1팀 엔티티는 식별자로 참조만 한다
