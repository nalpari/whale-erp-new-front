환경설정 & 시스템관리 · 물리 ERD

BP·플랫폼의 권한 그룹·공통코드·메뉴·휴일과 플랫폼 공식 휴일을 관리한다.

물리 보기만 모은 장이다. 논리 · 논리+물리 보기는 1팀 ERD 에서 본다.

개요인증·계정점포관리BP 관리환경설정 & 시스템관리

PostgreSQL 테이블·컬럼·타입이다. 타입 끝 ? 는 NULL 허용이다. 등록자·수정자(created_by·updated_by) 외래키는 모든 테이블에 있어 선을 생략한다.

중심

권한·공통코드·메뉴

  • 권한 그룹은 메뉴별 CRUD 4가지 권한을 정한다
  • 공통코드는 플랫폼고정·플랫폼제공·BP전용 3단계다
  • 플랫폼제공 그룹은 BP 적용 순간 모든 BP에 BP별 행으로 복사된다
  • 메뉴는 최대 3단계, 서비스 코드로 분류한다

BP 휴일과 공식 휴일

  • BP 휴일은 규칙 한 줄로 저장하고 날짜는 볼 때 계산한다
  • 특정 점포 휴일은 여러 점포를 묶고, 전체 점포 휴일은 예외 점포를 뺀다
  • 대상 · 예외 점포는 한 행이 한 기간이다 — 더하면 오늘부터, 빼면 어제까지 (2026-10-26)
  • 공식 휴일은 2000~2100년을 규칙으로 적재하고 올해·다음 해는 매월 1일 공공 API로 맞춘다

확정

  • 상세 코드에도 관리 주체를 저장한다 (CONFIG-7)
  • 메뉴는 삭제하지 않고 사용중지하며 변경 이력은 두지 않는다 (SYSTEM-7)
  • 메뉴 권한·공통코드·공식 휴일 변경 이력은 저장하지 않는다
  • 엑셀 다운로드는 모든 화면 공통 이력 한 테이블에 남기고 2년 보존한다 (2026-10-28)
