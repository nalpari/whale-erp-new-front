WHALE ERP · PHYSICAL ERD · 1차 범위 · 1팀

인증과 계정 · 물리 ERD

아이디(영문·숫자 4~20자)로 로그인하고 연속 5회 실패 시 5분 잠금한다. 접근 토큰 1시간, 갱신 토큰은 마지막 사용 후 1시간이다. BP 마스터가 사업자 회원가입으로 직접 만들거나, 플랫폼 관리자가 등록한다.

물리 보기만 모은 장이다. 논리 · 논리+물리 보기는 1팀 ERD 에서 본다.

개요인증·계정점포관리BP 관리환경설정 & 시스템관리

PostgreSQL 테이블·컬럼·타입이다. 타입 끝 ? 는 NULL 허용이다. 등록자·수정자(created_by·updated_by) 외래키는 모든 테이블에 있어 선을 생략한다.

중심

아이디로 로그인

  • 영문·숫자 4~20자 아이디로 로그인한다
  • 접근 토큰 1시간, 갱신 토큰은 마지막 사용 후 1시간이다
  • 여러 브라우저 동시 로그인을 허용한다

잠금과 임시비밀번호

  • 연속 5회 실패 시 5분 잠금한다
  • 임시·초기·초기화 비밀번호 모두 12자 무작위, 1시간 뒤 만료한다
  • 초기 발급은 찾기 1시간 5회 제한에 세지 않는다
  • 초기 비밀번호 발급 시 강제 비밀번호 변경 플래그를 켠다

3팀과의 경계

  • 관리자 계정(admin_accounts)은 1팀 소유다
  • BP 조직 정보는 bp_codes 테이블에서 관리한다
  • 3팀의 계정(accounts)·직원 레코드(staff_members)와는 별도 테이블이다
