핵심 갈림길 넷.
  • 사업자정보 인증(국세청 진위확인)은 회원가입 때도, 마이페이지 재인증 때도 선택이다 — 인증 없이도 가입·유지할 수 있고, 상호명은 인증 결과로 채워지지 않는다.
  • 강제 비밀번호 변경 대상 여부는 로그인 횟수가 아니라 계정에 저장된 표시로만 판정한다 — 회원가입으로 본인이 비밀번호를 정한 계정은 최초 로그인이어도 대상이 아니다.
  • 로그인에 성공하면 계정 유형에 따라 접속 사이트가 갈린다 — BP·가맹 마스터·관리자는 웨일ERP(BP) 홈으로, 플랫폼 마스터·관리자는 웨일ERP(플랫폼관리) 사이트로 이동한다(2026-09-29 F-DZVFIC 확정).
  • 회원 탈퇴 선행조건은 부가서비스 구독 해지 · 미정산 금액 0 · 진행 중 근로계약 0 세 가지뿐이다 — 점포는 조건이 아니며 상태와 무관하게 전부 폐점된다. 탈퇴하면 같은 BP의 하위 계정(BP 관리자·가맹 마스터·가맹 관리자)도 함께 탈퇴되어 개인정보를 지운다. 로그아웃·탈퇴처럼 스스로 세션을 끝내면 로그인 전 홈으로, 세션 타임아웃이면 로그인 화면으로 보낸다(2026-09-29 확정).

확정된 결정

아이디·이메일 중복확인은 포커스아웃 시 즉시, 사업자번호 중복확인은 국세청 인증 전에 먼저 수행. 로그인 판정 순서는 잠금→아이디비밀번호→계정상태→강제변경 고정. 로그인 성공 시 BP측 계정은 웨일ERP(BP) 홈, 플랫폼 계정은 웨일ERP(플랫폼관리) 사이트로 이동(2026-09-29 확정). 비밀번호 변경 시 다른 기기 세션은 모두 종료하되 현재 세션은 유지. 아이디 찾기 결과는 앞 2자·뒤 1자만 노출. 5회 연속 로그인 실패 시 5분 잠금(임시비밀번호 발급으로만 즉시 해제). 초기·임시 비밀번호는 발급 후 1시간 유효, 임시비밀번호는 계정당 1시간 5회 제한. 로그아웃·회원탈퇴처럼 스스로 세션을 끝내면 로그인 전 홈으로, 세션 타임아웃이면 로그인 화면으로 이동(2026-09-29 확정). 회원탈퇴는 구독 해지·정산 0·근로계약 0을 모두 충족해야 가능하며, 같은 BP의 하위 계정(BP 관리자·가맹 마스터·가맹 관리자)도 함께 탈퇴되어 개인정보를 지우고, 탈퇴한 계정의 아이디는 재사용할 수 없으며 그 BP의 모든 점포는 상태와 무관하게 즉시 폐점된다.

밖에 있는 것

판매용 부가서비스 회원과 직원 전용 앱 계정은 이 범위에서 제외한다(별도 가입·인증 체계). 회원가입 과정에서는 점포를 등록하거나 자동 생성하지 않는다 — 점포 등록은 별개 기능이다. 점포 운영 여부는 회원 탈퇴의 조건이 아니며, 이 화면은 탈퇴로 점포가 폐점되는 결과까지만 다루고 점포 개별 처리는 그리지 않는다.
