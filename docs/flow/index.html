여섯 열 제한 때문에 웹 전체를 한 장에 넣지 않고 업무 흐름 단위로 나눴다. 링크는 라이트 테마로 열리고(?theme=light), 한 번 고른 테마는 그 브라우저에 기억된다. 뷰어 버튼 글자는 영어다. 원본은 각 폴더의 *.workflow.json 이고 archify 스킬로 다시 만든다. 목업의 결정이 바뀌면 그 장의 JSON 을 고쳐 다시 낸다.
